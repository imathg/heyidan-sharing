# DVAO：多目标 RL 里按方差自适应的优势组合

<!-- domain: agentic-rl -->

`[论文]` [DVAO](#ref-dvao)（arXiv:2605.25604，阿里云团队，2026）针对一个 GRPO 下很常见的工程问题：多个互相冲突的奖励——数学推理的"答对" vs "别无限套娃"（长度）、工具调用的"参数对" vs "JSON 格式合法"——要标量化成一个标量再做 group-relative 优化，"直接合"为什么会塌、怎么合才稳。

`[本文归纳]` 这篇值得单独拎出来，是因为它把"多个奖励信号粗暴合一时，强目标被弱/易目标吃掉"这件工程上反复踩的事，用 GRPO 框架下的两条闭式命题写清楚了。

## 两类"直接合"各自的病灶

`[论文]` 论文把主流标量化分成两类，各证一个病灶：

- **奖励组合（RC, Reward Combination）**：先加权求和原始奖励、再统一归一化。Proposition 1 证明，当目标间冲突（样本相关系数 ρ<1）时，RC 的均方优势恒 ≥ 优势组合，归一化又把组合方差强行拉回 1、抹掉冲突的抵消效应——等于在冲突剧烈时变相放大优势数值，引发巨大梯度更新、训练失稳。
- **优势组合（AC，如 GDPO）**：先对每个目标独立归一化得各自优势、再加权求和。把组合方差压到 ≤1 稳住了梯度幅值，但用静态权重、且归一化时把各目标完全隔离，梯度信息完全解耦（∇J = Σ wk ∇Jk），抓不到单次 rollout 内多目标的协同/对抗关系，易陷次优。

## DVAO：用组内经验方差动态加权

`[论文]` DVAO（Dynamic Variance-adaptive Advantage Optimization）把静态权重换成数据驱动的动态权重：对每个 rollout 组先算各目标经验标准差 σk，自适应权重 `w̃k = wk·σk / Σ wl·σl`。直觉是"强信号放大、弱/噪声信号抑制"——某目标组内方差大（回复有好有坏、区分度高）说明学习信号强，调大权重；方差近 0（都差不多或太易满分）则压低。

两条理论保障：

- `[论文]` **Proposition 2（有界性）**：`|A_DVAO| ≤ |A_sum|` 逐点成立，以 RC 为上确界，天然防梯度爆炸；等号当且仅当奖励两两完美正相关。
- `[论文]` **Proposition 3（隐式交叉正则）**：DVAO 偏导敏感度由交叉项 `A_DVAO·A_k` 决定（AC 是孤立的 `A_k²`），把单目标表现和全局表现绑定——某样本目标 k 上好、全局差时敏感度被放大，迫使模型优先补全局短板；全局局部都好时敏感度收缩，防止在易优化目标上过度压榨核心目标。

## 实验：双赢且支配帕累托前沿

`[论文]` verl 框架、G=16、500 步（math 用 Qwen3-4B/8B-Base，tool-use 用 Qwen2.5-3B/7B-Instruct，BFCL-v4）：

| 方法 | 现象 |
|------|------|
| 单目标 GRPO | 准确率升、长度依从崩（Qwen3-8B 94.28%→63.47%） |
| RC / AC | 长度拉回 96%+ 但准确率回落（8B RC 52.57%→46.26%） |
| GDPO | 灾难性崩溃（4B 准确率塌到 13.41%，彻底倒向"长度"这个易满分目标） |
| DVAO | 双赢（4B 42.19% / 99.91%，8B 47.49% / 99.92%），反超单目标 GRPO |

`[论文]` 在 w1∈{0.1,0.3,0.5,0.7,0.9} 扫参下，DVAO 在"准确率 vs 依从度"平面右上角绝对支配，AC 在大部分权重下崩溃。

## 局限

`[论文]` 论文自陈三条：

1. **G 下限依赖**：G≤4 时组内方差估计误差大，可引历史动量 / 跨批次滑动平均。
2. **高维冲突扩展性**：只实证双目标，多目标空间未验。
3. **辅助奖励质量瓶颈**：DVAO 是"信号放大器"，若某目标本身是高方差随机噪声，会被误判为强信号而调大权重——合并算法救不了坏信号。

`[本文归纳]` 一句话：DVAO 把"按信号区分度分配训练权重"这条直觉做成了连续、可证有界的优势加权。它和"按场景/样本切分把冲突信号物理隔离"那类离散工程解法正交——两者可叠加。
