Agent Harness：状态管理、长期记忆与 Skill 复用

这里整理模型外的状态管理、长期记忆和执行经验复用。了解 Harness 的改进方式，可以先读 《Agent Harness 如何学习：状态读写策略与运行代码演化》：它比较训练模型使用既有接口与修改运行程序两类方法，说明各自改变什么、需要什么反馈。

长期记忆中的事实更新与证据追溯

《Agent 长期记忆：更新过时事实，保留可追溯证据》 适合排查沿用旧计划、检索被噪声干扰、摘要丢失来源等问题。文章分别讨论事实版本、检索选择和可恢复压缩，帮助判断需要调整哪一部分记忆管理。

Skill 的可靠性与经验的复用粒度

  • 已有 Skill，却出现无效调用、跳步、越权或有害经验回写，读 《Agent Skill 为何失效：无效调用、执行偏离与错误经验回写》。它按具体风险比较启用、执行和更新时的诊断与验证方法。
  • 准备从一次执行中提炼经验，读 《Agent 执行经验：复用粒度与部署条件》。它比较精确重放、参数化操作和共享解题骨架的适用条件，并讨论提炼后的经验何时可以投入使用。

前一篇用于检查 Skill 怎样失效，后一篇用于选择经验应该保留成什么形式。

团队能力与知识的组织分发

落实到团队仓库时，读长文 《AI repo，其实就是一套团队级 harness》。它讨论能力仓、知识库、工作区隔离，以及 plugin、Skill、CLI 等资产怎样被发现和更新，适合规划团队共用的工程设施。
