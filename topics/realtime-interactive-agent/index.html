实时交互 Agent：话轮控制与全双工评测

这两篇分别用于设计实时交互行为和定位全双工语音错误。设计系统时先读控制篇；已有交互轨迹、需要核对输入与播放状态时，可以直接读评测篇。

话轮控制、后台协作与延迟预算

《实时交互 Agent：话轮控制、后台协作与延迟预算》 讨论何时开口、何时让出话轮、怎样委派后台任务，以及服务与安全检查怎样消耗响应时间。适合梳理前台互动、后台执行和部署约束之间的接口。

输入、播放与打断状态的对齐

《全双工语音 Agent 评测：输入、播放与打断状态如何对齐》 关注模型取得了什么输入、客户端播放到哪里、打断后继承了什么状态。它对照分层记录与局部实验，帮助定位感知、上下文、语音生成或对话策略的问题，并区分工程检查与真实用户体验的证据。
