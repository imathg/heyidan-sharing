DVAO：多目标 RL 里按方差自适应的优势组合

date 2026-06-11 sources 3 domain agentic-rl slug dvao-multireward

论文 DVAO（arXiv:2605.25604，阿里云团队，2026）处理 GRPO 下的一类常见工程问题：多个互相冲突的奖励，比如数学推理的「答对」与「控制长度」、工具调用的「参数正确」与「JSON 格式合法」，都要标量化后再做 group-relative 优化。论文讨论直接合并为何失稳，以及如何稳定合并。

本文归纳 它用 GRPO 框架下的两条闭式命题，形式化说明了直接合并多个奖励信号时，重要目标会被弱信号或易满足目标淹没这一常见现象。

两类直接组合的局限

论文 论文将主流标量化分成两类，各自揭示一类问题（三条命题的中文解读见 此文）：

  • 奖励组合（RC, Reward Combination）：先加权求和原始奖励、再统一归一化。Proposition 1 证明，当目标间冲突（样本相关系数 ρ<1）时，RC 的均方优势恒 ≥ 优势组合；归一化又将组合方差恢复为 1，抹去冲突带来的抵消效应，使优势数值在冲突剧烈时被变相放大，引发过大的梯度更新和训练失稳。
  • 优势组合（AC，如 GDPO）：先对每个目标独立归一化得各自优势、再加权求和。组合方差被限制在 ≤1，梯度幅值较稳定；但静态权重和独立归一化将各目标隔离，梯度信息完全解耦（∇J = Σ wk ∇Jk），无法反映单次 rollout 内多目标的协同或对抗关系，容易停在次优解。

DVAO：用组内经验方差动态加权

论文 DVAO（Dynamic Variance-adaptive Advantage Optimization）将静态权重换成数据驱动的动态权重：对每个 rollout 组先算各目标经验标准差 σk，自适应权重 w̃k = wk·σk / Σ wl·σl。组内方差大（回复有好有坏、区分度高）说明学习信号较强，权重随之提高；方差接近 0（样本差异很小或容易满分）则降低权重。

两条理论保障：

  • 论文 Proposition 2（有界性）：|A_DVAO| ≤ |A_sum| 逐点成立，以 RC 为上确界，因此可避免梯度爆炸；等号当且仅当奖励两两完美正相关。
  • 论文 Proposition 3（隐式交叉正则）：DVAO 偏导敏感度由交叉项 A_DVAO·A_k 决定（AC 是孤立的 A_k²），将单目标表现和全局表现绑定：某样本在目标 k 上表现好而全局表现差时，敏感度随之放大，促使模型优先补足全局短板；全局和局部都好时，敏感度收缩，避免在易优化目标上过度消耗核心目标。

实验：两项目标均改善，并位于帕累托前沿

论文 verl 框架、G=16、500 步（math 用 Qwen3-4B/8B-Base，tool-use 用 Qwen2.5-3B/7B-Instruct，BFCL-v4）：

方法 现象
单目标 GRPO 准确率升、长度依从度大幅下降（Qwen3-8B 94.28%→63.47%）
RC / AC 长度依从度恢复至 96%+，但准确率回落（8B RC 52.57%→46.26%）
GDPO 灾难性失效（4B 准确率跌到 13.41%，几乎只优化"长度"这个易满分目标）
DVAO 双赢（4B 42.19% / 99.91%，8B 47.49% / 99.92%），反超单目标 GRPO

论文 在 w1∈{0.1,0.3,0.5,0.7,0.9} 扫参下，DVAO 在「准确率与依从度」平面形成绝对支配，AC 在大部分权重下失效。

局限

论文 论文自陈三条：

  1. G 下限依赖：G≤4 时组内方差估计误差大，可引入历史动量 / 跨批次滑动平均。
  2. 高维冲突扩展性：只实证双目标，多目标空间未验。
  3. 辅助奖励质量瓶颈：DVAO 是"信号放大器"，若某目标本身是高方差随机噪声，DVAO 会把它当成强信号、调大权重，合并算法处理不了低质量信号。

本文归纳 DVAO 将「按信号区分度分配训练权重」定义为连续、可证明有界的优势加权。它与按场景或样本切分、分开优化冲突信号的离散工程做法正交，两者可以叠加。
