# Agent 强化学习：GRPO、多目标优化与步骤信用

比较 Agent RL 训练方案，可以先读 [《GRPO 变体比较：归一化、裁剪与轨迹信用分配》](../../briefs/grpo-variant-axes/)。它按更新样本、归一化、裁剪和优势基线等设计选择对照方法，适合先分清不同算法名称实际改了哪里。

## 多个奖励怎样组合

[《DVAO：多目标 RL 里按方差自适应的优势组合》](../../briefs/dvao-multireward/) 聚焦准确率与长度依从度等多目标取舍，比较先合并奖励、分别归一化优势和动态加权。需要调整奖励组合时读这篇；其中优势幅值的理论分析与实验中的目标取舍分别讨论。

## 执行证据与中间步骤信用

- 训练数据只有最终答案和成败标签，读 [《Agent RL 的轨迹证据：环境如何把执行过程变成训练信号》](../../briefs/agent-trajectory-evidence/)。它对照动作后果、稳定对象地址、测试与过程评分等记录，说明这些证据怎样进入任务筛选、SFT 和 RL。
- 已有轨迹与反馈，需要区分成功轨迹中的坏步、失败轨迹中的好步，读 [《长程 Agent RL：如何给中间步骤分配信用》](../../briefs/long-horizon-credit-assignment/)。它比较局部信用的参照信号、额外监督成本与 critic 的使用条件。

前者关注环境留下什么，后者关注怎样把反馈分配给步骤。可以按当前是在构造训练环境，还是调整学习信号，选择对应文章。
