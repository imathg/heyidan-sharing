本站约定

跨文章共享的术语、记号、编辑规范。文章正文用一句话引用，不每篇赘述。

Claim 出处标签

本站每篇技术文章的正文 claim 都带四档 tag 之一，标注这条 claim 的可信度等级。读者扫一眼 tag 即知是哪一类证据。

Tag 含义
[论文] arxiv / 同行评审论文报告的具体实验，作者署名与机构可查。
[tech report] 工业系统自报数据、团队内部 wiki 调研、业界转述等无完整论文支撑、但有明确 release/出处的工业级 claim。
[个人实验] 个人 X 长文 / 博客 / Substack 上单人 setup 的实验，无独立复现。
[本文归纳] 本文作者在跨源 reduce 过程中得到的命题，没有单一外部源；可作为思路启发，不能作为决策依据。
Reference section 内的每条文献末尾也带 tag（例 [arxiv 论文]、[tech report / 业界转述，无 arxiv 论文]、[个人实验 / X 长文]、[工程博客]），含义与上表对应。

为什么不用置信度数字

读者用 tag 反推出处类型一步到位，比"高 / 中 / 低"或百分比信息密度更高。同时把"是不是单人实验"、"是不是工业自报"这种关键边界条件直接刻在 tag 里，避免在正文里反复用否定句式打补丁。
